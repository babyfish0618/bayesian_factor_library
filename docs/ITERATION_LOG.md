### 核心发现

#### 1. 三套评价标准体系
```
1. 采样打分标准 (选择时使用)
   - 贝叶斯部分: Thompson Sampling (权重0.7)
   - 近期表现: ICIR归一化 (权重0.3)

2. 判断成功-选中因子 (更新参数)
   - ICIR > 0.8 且 排名 < 0.7 (前70%)
   - 成功: α+1, 失败: β+1

3. 判断成功-没选中因子 (边际贡献)
   - ICIR > 1.5 (更严格)
   - 相关性 < 0.6 (与选中因子)
   - 边际贡献 > 0 (模拟)
   - 成功: α+1, 失败: 不更新
```

#### 2. 关键参数设置
```python
# 采样打分权重
'bayesian': 0.7,      # Thompson Sampling
'recent_perf': 0.3,   # 近期ICIR

# 成功阈值
'selected_icir': 0.8,      # 选中因子ICIR阈值
'selected_rank': 0.7,      # 选中因子排名阈值
'unselected_icir': 1.5,    # 没选中因子ICIR阈值(更严格)
'unselected_corr': 0.6,    # 没选中因子相关性阈值

# 时间窗口
'recent_performance': 3,   # 近期表现回看期数
```

#### 3. 与AlphaPROBE的对比
| 维度 | AlphaPROBE | 我们的实现 |
|------|-----------|-----------|
| **没选中因子评估** | 未明确提及 | ✅ 专门设计边际贡献法 |
| **评价标准区分** | 可能统一 | ✅ 明确三套不同标准 |
| **相关性考虑** | DAG结构 | ⚠️ 简单相关性阈值 |
| **边际贡献模拟** | 未明确提及 | ⚠️ 启发式模拟 |
