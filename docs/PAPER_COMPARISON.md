# 与AlphaPROBE论文对比分析

## 项目背景对比

| 维度 | AlphaPROBE (原论文) | 我们的项目 |
|------|-------------------|-----------|
| **核心问题** | 因子生成和演化 | 因子库维护和选择 |
| **输入** | 初始因子 + LLM生成新因子 | 现有因子库（N个因子） |
| **输出** | 新生成的因子 + DAG演化历史 | 选择的K个最优因子 |
| **应用场景** | 因子发现研究 | 因子库维护和组合构建 |

### 3. DAG结构

#### AlphaPROBE：
- 完整DAG记录因子演化历史
- 用于理解因子间的演化关系
- 支持复杂的演化路径分析

#### 我们的实现（当前）：
- 简化：只记录选择历史
- 后续：可以添加简化DAG记录因子替换关系

### 4. 数据流对比

#### AlphaPROBE数据流：
```
初始因子 → LLM生成 → 评估 → 加入DAG → 作为新父因子
      ↑_____________贝叶斯选择___________|
```

#### 我们的数据流：
```
现有因子库 → 贝叶斯选择 → 选中因子 → 实际使用
      ↑________更新贝叶斯参数_________|
```

### 3. 数据模拟方法

- **真实数据**：使用Qlib的A股数据
- **因子计算**：基于价格、成交量等原始特征
- **表达式解析**：完整的算子体系（Abs, Log, TsMean等）

## 技术债务与改进空间

### 从AlphaPROBE可以借鉴的：
1. **DAG结构**：记录因子替换关系，理解演化路径
2. **维度分析**：确保因子可比性的数学框架
3. **LLM集成**：未来可以用于生成因子解释
4. **真实数据接口**：连接Qlib等量化数据库

### 我们的创新贡献：
1. **将贝叶斯优化应用于因子选择**（而非生成）
2. **三套评价标准体系**
3. **边际贡献评估方法**
4. **分层替换策略**
5. **可控数据模拟框架**

## 总结

我们**不是简单复制**AlphaPROBE，而是：
1. **抽取核心模块**：贝叶斯优化
2. **应用于新问题**：因子库维护
3. **扩展和深化**：多维度评价、边际贡献评估
4. **补充基础**：可控数据模拟框架
5. **保持连接**：记录与原文的异同，便于回溯和验证

这种"模块抽取+独立应用+基础补充"的研究方法，可以系统性地从论文中挖掘价值，解决实际问题，同时为后续研究打下坚实基础。
