## 核心功能实现

### ✅ 正确的股票数据模拟器
```python
# 精确的IC控制公式
F = ρR + √(1-ρ²)Z
# 其中：corr(F, R) = ρ = IC_t
# R = 标准化后的t+1期收益
# Z ~ N(0,1) 且与R独立（通过正交化实现）
```

### ✅ IC参数设计
- IC序列：`IC_t ~ N(μ_k, σ_fixed²)`
- ICIR_k = μ_k / σ_fixed（只取决于IC均值）
- 固定IC方差，通过IC均值区分因子质量

### ✅ 得分加权多空组合
- 多头权重：正比于得分，权重和=1
- 空头权重：正比于得分绝对值，权重和=-1
- 总杠杆：2.0

### ✅ 时间对齐
- t期因子得分 `F_t`
- t+1期收益 `R_{t+1}`
- 要求：`corr(F_t, R_{t+1}) = IC_t`
